JWT 检查台

粘贴 Bearer token 或原始 JWT，本地解析 header、payload 和时间字段。适合认证排查、API 调试、IAM/网关核对，以及快速识别未签名、过期或结构异常 token。

Token 输入

当前只做本地结构检查，不验证签名真伪，也不请求远端 JWKS。适合做“先看结构、再决定是否深挖”的第一步分析。
输出重点面向中文安全工作流：快速判断 token 是否未签名、是否过期、是否缺少关键 claims，以及 header / payload 里是否有异常认证字段，便于后续写工单或接入任务模板。
