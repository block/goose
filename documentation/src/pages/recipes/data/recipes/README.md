# Community Recipe Cookbook

This directory contains the recipes displayed in the [Recipe Cookbook](https://goose-docs.ai/recipes). It remains available as an archive, but the public submission program has ended and we are not accepting new community recipe submissions.

You can still create, use, and share your own recipes. See the [recipe documentation](https://goose-docs.ai/docs/guides/recipes) for details.

The archived **Add MCP Server** recipe does not represent the current submission process. goose no longer accepts new third-party entries in `documentation/static/servers.json`. Server authors should publish to the [official MCP Registry](https://github.com/modelcontextprotocol/registry) using its `server.json` format; see [Discussion #10830](https://github.com/aaif-goose/goose/discussions/10830).
