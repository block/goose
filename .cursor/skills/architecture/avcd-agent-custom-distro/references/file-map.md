# Avocado Work custom-distro file map

Paths are relative to the `avcd-agent` repository root.

## Official upstream guide

| Path | Notes |
|------|-------|
| `CUSTOM_DISTROS.md` | Full custom distribution guide; **§D Custom Branding and UI** |
| `BUILDING_DOCKER.md` | Docker build / provider env examples |
| `BUILDING_LINUX.md` | Linux packaging |
| `ui/desktop/README.md` | Desktop build notes |
| `documentation/docs/` | Docusaurus site sources (optional) |

Published: https://block-goose.mintlify.app/advanced/custom-distributions

## Branding — desktop shell

| Path | What to change |
|------|----------------|
| `ui/desktop/forge.config.ts` | App name, executable, icons, protocol, makers, GitHub publisher |
| `ui/desktop/package.json` | `productName`, description, `bundle:*` / `debug` scripts |
| `ui/desktop/index.html` | Window title |
| `ui/desktop/forge.deb.desktop` | Linux DEB desktop entry name |
| `ui/desktop/forge.rpm.desktop` | Linux RPM desktop entry name |
| `ui/desktop/vite.main.config.mts` | Build-time `GITHUB_*` + `GOOSE_BUNDLE_NAME` defaults |
| `ui/desktop/src/app-update.yml` | Auto-update feed / owner-repo |
| `ui/desktop/src/utils/githubUpdater.ts` | Uses `GOOSE_BUNDLE_NAME` for asset matching |
| `ui/desktop/src/main.ts` | About/hide/focus menus, error dialogs, app name |
| `ui/desktop/src/i18n/messages/en.json` | User-facing product strings |
| `ui/desktop/src/images/*` | Icons, tray templates, splash |

## Local development / distro runtime

| Path | Role |
|------|------|
| `Makefile` | Public API: `dev`, `dev-ui`, `validate-openrouter`, `test-smoke`, secrets |
| `docker-compose.yml` | ACP server + CLI profiles, `env_file`, provider env |
| `Dockerfile.dev` | Dev image for `goose serve` |
| `.env.local.example` | Documented local variables |
| `.env.local` | Secrets (gitignored) |
| `scripts/prepare-dev-ui-env.sh` | Generates `ui/desktop/.env` for external backend |
| `scripts/with-node.sh` | Pin Node 24+ for desktop tooling |
| `scripts/validate-openrouter-preset.sh` | Preset validation |
| `scripts/smoke-test.sh` | Branding + backend smoke (invoked by `make test-smoke`) |
| `config/avcd-openrouter-models.json` | OpenRouter catalog |

## Desktop generated / runtime (do not commit secrets)

| Path | Role |
|------|------|
| `ui/desktop/.env` | Generated by `prepare-dev-ui-env.sh` |
| `ui/desktop/out/` | Packaged apps (`Avocado Work.app`, zips) |
| `~/Library/Application Support/Avocado Work/` | Electron userData + `logs/main.log` |
| Docker volume `…/goose/config.yaml` | Persisted container config (`/home/goose/.config/goose/`) |

## Upstream customization points (beyond branding)

From `CUSTOM_DISTROS.md` key table:

| Goal | Location |
|------|----------|
| Preconfigure provider | `config.yaml`, `init-config.yaml`, env |
| Declarative providers | `crates/goose/src/providers/declarative/` |
| Bundled MCP extensions | `ui/desktop/src/built-in-extensions.json`, Settings bundled JSON, compose config |
| Recipes | YAML recipes under project / user recipe dirs |
| Custom UI over ACP | `goose serve` HTTP/WS — see §E |

## Grep helpers

```bash
# Product name leftovers
rg -n "\\bGoose\\b|goose\\.app|aaif-goose" ui/desktop crates/goose/src/prompts \
  --glob '!node_modules/**' --glob '!**/out/**'

# Updater / publisher alignment
rg -n "GITHUB_OWNER|GITHUB_REPO|GOOSE_BUNDLE_NAME|publisher-github" \
  ui/desktop/forge.config.ts ui/desktop/vite.main.config.mts ui/desktop/src
```
